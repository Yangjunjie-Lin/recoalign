# M0 — Historical Anchor

M0 serializes the active entity bindings as A2-style canonical JSON keyed by `Entity A` through
`Entity D`. It contains an empty relation inventory and no relation, query role, reasoning field, or
answer field. Alias assignment and JSON content are scene-bound and model-output-independent.

M0 is descriptive only. It cannot be selected even if it outperforms M1 and M2.
