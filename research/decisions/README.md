# Scientific decision records

This directory stores immutable, reviewed GO/NO-GO records derived from registered experiment runs.
Generated, schema-valid `decision_report.yaml` files remain inside their run directories until
reviewed; `decision_report.md` is only a readable mirror. A YAML report may be copied here only with
its run ID, registry/config digests, reviewer, review date, and any declared deviations. Favorable
metrics never authorize changing a preregistered rule.
