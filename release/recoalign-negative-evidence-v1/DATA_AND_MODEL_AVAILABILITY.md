# Data and Model Availability

## Included in the repository or evidence release

- source code;
- configurations and frozen protocols;
- lightweight metrics and decision reports;
- compressed prediction records;
- figures and artifact manifests;
- synthetic-world metadata and generation infrastructure; and
- governance, preregistration, adjudication, and closeout records.

## Not included

- LLaVA checkpoint bytes;
- CLIP or OpenCLIP checkpoint bytes;
- restricted dataset images;
- gated annotations;
- local model or dataset caches;
- generated feature arrays;
- private credentials; and
- newly generated inference outputs.

The model identifier and exact revision are recorded for provenance, but model availability and
license terms are controlled by the upstream provider. Users must obtain any third-party model or
dataset independently and comply with its terms. The Apache-2.0 license of this repository does not
license third-party models, weights, data, images, annotations, or other separately governed assets.
